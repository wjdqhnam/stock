# 첫주식

주식을 처음 하는 사람을 위한 국내 주식 분석 웹사이트입니다.
코스피·코스닥 전 종목(스팩 제외 약 2,600개)을 매일 장 마감 후 분석해서 **어떤 종목을, 얼마에 사서, 얼마에 팔지**를 쉬운 말로 알려줍니다.

> 이 사이트의 정보는 과거 가격으로 계산한 참고 자료이며 투자 권유가 아닙니다.

## 주요 기능

- **오늘의 판정**: 종목마다 `사볼 만해요 / 기다려요 / 쉬어가요` 세 가지로 판정
- **가격 계획**: 살 가격(매수 구간), 목표가, 손절가를 원 단위로 제시 (한국거래소 호가 단위에 맞춤)
- **판단 근거**: 왜 그렇게 판정했는지 전문 용어 없이 설명
- **투자금 계산기**: 금액을 넣으면 몇 주를 살 수 있고, 목표가·손절가에서 얼마를 벌거나 잃는지 계산
- **과거 성적(백테스트)**: 같은 규칙을 지난 4년에 적용했을 때의 적중률과 평균 수익을 함께 공개
- **초보자 안전 필터**: 거래가 적거나, 상장 초기이거나, 너무 출렁이는 종목은 추천하지 않음
- **재무·공시 경고** (OpenDART 키가 있을 때만): 영업적자, 유상증자, 횡령·배임 같은 위험 공시를 판정에 반영

## 실행 방법

Python 3.10 이상이 필요합니다. 외부 패키지는 FastAPI와 Uvicorn뿐이고, 분석 로직은 표준 라이브러리만 사용합니다.

```bash
python -m venv .venv
.venv\Scripts\activate          # macOS/Linux: source .venv/bin/activate
pip install fastapi uvicorn pytest httpx

uvicorn stock_app:app --port 8000
```

브라우저에서 http://127.0.0.1:8000 을 엽니다.

- **처음 실행**하면 전 종목 300일 치 시세를 모으느라 2~3분 걸립니다. 그동안 화면에 안내 문구가 나옵니다.
- 그 뒤로는 서버가 켜져 있는 동안 **평일 15:40 이후 하루 한 번** 자동으로 새 시세를 받습니다.
- 수동으로 수집하려면 `python market.py`를 실행합니다.

### 재무·공시 기능 켜기 (선택)

[OpenDART](https://opendart.fss.or.kr)에서 무료 인증키를 발급받아 환경변수로 넣으면 자동으로 켜집니다.

```powershell
[Environment]::SetEnvironmentVariable("DART_API_KEY", "발급받은키", "User")
```

### 과거 성적 다시 계산 (선택)

```bash
python backtest.py      # 약 30초~1분, backtest.json 생성
```

### 테스트

```bash
python -m pytest -q
```

## 판정 방식

최근 300거래일의 일별 가격·거래량만 사용합니다.

1. **추세**: 종가와 20일·60일 평균 가격의 위치로 오름세 / 내림세 / 방향 미정을 판단합니다.
2. **점수**: 오름세 +2, 내림세 −2, 골든·데드크로스 ±1, 과열(RSI 70 이상) −1, MACD 교차 ±1
3. **판정**
   - 쉬어가요: 내림세이거나 점수 −2 이하
   - 사볼 만해요: 오름세이고, 가격이 매수 구간 안에 있고, 과열이 아님
   - 기다려요: 나머지
4. **가격 계획**: 하루 평균 변동폭(ATR) 기준
   - 매수 구간: 20일 평균 근처 또는 현재가 바로 아래
   - 손절가: 기준가 − 2×ATR
   - 목표가: 기준가 + 4×ATR (목표 수익이 감수할 손실의 2배)
5. **초보자 안전 필터**: 하루 거래대금 10억 원 미만, 상장 120일 미만, 하루 변동폭 8% 이상이면 `사볼 만해요`를 `기다려요`로 낮춥니다.
6. **재무·공시** (DART 키가 있을 때): 횡령·배임·거래정지·관리종목·감자 공시나 자본잠식이면 `쉬어가요`, 유상증자·전환사채·영업적자면 `사볼 만해요`를 `기다려요`로 낮춥니다.

## 과거 성적 (백테스트)

대형주 68개, 2022년 10월 ~ 2026년 11월. 그날 장 마감 데이터로 판정하고 다음 날 시가에 산 것으로 계산했습니다. 거래 비용 0.25%를 빼고, 같은 날 손절가와 목표가를 모두 건드리면 손절로 쳤습니다.

| 판정일에 샀다면 | 목표가 도달 | 거래당 평균 수익 |
|---|---|---|
| 사볼 만해요 (실제 신호 1,010번) | 41.4% | +2.06% |
| 기다려요 | 42.2% | +0.96% |
| 쉬어가요 | 37.0% | −0.17% |
| 아무 날이나 | 39.9% | +0.60% |

목표 수익이 손실의 2배라서 10번 중 3.4번만 맞아도 본전입니다. 적중률은 목표가를 가깝게 잡으면 얼마든지 올릴 수 있지만(손실 폭의 0.5배로 잡으면 78%), 그러면 평균 수익이 0에 가까워집니다. 그래서 적중률보다 **거래당 평균 수익**을 기준으로 봅니다.

**한계**: 지금 살아남은 대형주만으로 계산해서 실제보다 좋게 나왔을 수 있고(생존 편향), 이 기간 시장 상승의 영향도 섞여 있습니다. 소형주에 같은 성적이 나온다는 보장은 없습니다.

## 파일 구조

| 파일 | 역할 |
|---|---|
| `stock_app.py` | 웹 서버 (FastAPI). 시세를 메모리에 올려 분석하고 API 제공, 하루 한 번 자동 수집 |
| `stock.py` | 지표 계산(이동평균, RSI, MACD, ATR)과 판정·가격 계획 |
| `market.py` | 종목 목록·시세 수집과 저장 (SQLite `market.db`) |
| `dart.py` | OpenDART 재무·공시 조회와 판정 보정 |
| `backtest.py` | 과거 성적 계산 → `backtest.json` |
| `static/` | 화면 (HTML·CSS·JavaScript, 빌드 과정 없음) |
| `test_*.py` | 테스트 |

## 데이터 출처와 주의사항

| 데이터 | 지금 | 앞으로 |
|---|---|---|
| 종목 목록·업종 | 한국거래소 KIND 상장법인 목록 | KRX Open API |
| 일별 시세 | 네이버 증권 차트 데이터 (임시) | KRX Open API |
| 재무·공시 | OpenDART (키 필요) | 그대로 |

- **네이버 증권은 자동 수집을 금지(robots.txt)하고 있습니다.** 지금 방식은 개인 테스트용 임시 방식이고, 동시 요청 4개·하루 1회로 부담을 줄였습니다. 공개하거나 판매하기 전에는 KRX Open API로 바꿔야 하며, `market.py`의 `listing()`과 `history()` 두 함수만 교체하면 됩니다.
- 외국인·기관 매매(수급) 데이터는 정식 무료 출처가 없어 반영하지 않았습니다.
- 이 사이트로 돈을 받고 특정 종목의 매수·매도를 추천하면 유사투자자문업 신고 대상이 될 수 있습니다.
